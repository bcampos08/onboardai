# Design documents

- `System_Architecture_Diagram_v3.png`: the system architecture diagram.
- `design-specification.md`: the full Design Specification. Export it from the editable doc as **Markdown** and save it here, so changes show up line by line in pull requests.

**Section 3 (Interface Contracts) is the source of truth for API paths, JSON field names, and function signatures.** If code needs a contract change, update this folder in the same pull request and request a review from the section owner.
